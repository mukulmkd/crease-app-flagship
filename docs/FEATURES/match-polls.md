# Feature: Match Polls

Each confirmed match has:

1. Availability poll (playing / not)
2. Carpool poll (carpool ₹100 to-and-fro vs own travel)

## Rules

- Visible roster of who opted in
- Soft target ≥ 11 available; hard cap 12 in service
- Votes changeable until freeze (match day − 1)
- Reminder cadence documented in PRODUCT / notifications rules
