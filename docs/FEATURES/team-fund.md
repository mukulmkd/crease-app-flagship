# Feature: Team Fund

Admin tracker for Ranches Thunders funds on `/expenses` (Admin-only).

- Balance + totals for contributions and expenses
- Per-player contribution totals (Admin records offline payments → credits fund)
- Expenses decrease balance immediately (**Add expense**)
- **Ask for funds** — Admin enters amount per player → WhatsApp group + in-app notify
- Balance also shown on Home status rail via `DashboardSnapshot.fundBalanceInr`
